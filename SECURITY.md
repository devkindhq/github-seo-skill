# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/devkindhq/github-seo-skill/security/advisories/new).

Relevant reports include the audit checks running unintended commands, or skill instructions that
could lead an agent to leak secrets or publish private data.

## Scope

This project contains documentation and read-only commands that call the GitHub CLI.
It has no runtime service and stores no data.
